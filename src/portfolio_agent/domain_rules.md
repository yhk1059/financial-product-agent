# 도메인 규칙

`generate_query` 프롬프트에 들어가는 도메인 규칙입니다.

- 규칙은 `## 공통` 또는 `## <테이블명> (설명)` 섹션 아래에 씁니다. 섹션 제목의 첫 단어가 `공통`이거나 테이블명과 정확히 같아야 합니다. `공통`과 선택된 테이블의 섹션만 프롬프트에 들어갑니다.
- 이 머리말처럼 첫 `## ` 섹션 앞에 있는 내용은 프롬프트에 들어가지 않습니다.
- 규칙은 골든 데이터셋 실행에서 확인한 실패를 근거로 하나씩 추가하고, 끝에 근거 문항을 적습니다. 예: `- … (근거: C1-05, C3-05)`
- 이전 규칙은 `domain_rules_legacy.md`에 보관되어 있습니다. 에이전트는 그 파일을 읽지 않습니다.
